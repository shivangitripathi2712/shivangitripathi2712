## About Me

I am a **Ph.D. student in Computer Science at Texas State University**, working on **Large Language Model reliability, hallucination detection and correction, misinformation revision, adversarial robustness, and trustworthy AI**.

My research aims to make generative AI systems more **factually grounded, robust, and safe for real-world deployment**, especially in long-form generation and security-sensitive settings.

## Featured Research Projects

### [Long-Output Misinformation Revision](https://github.com/shivangitripathi2712/long_output_misinformation_revision)
Evidence-grounded sequential revision framework for correcting **paragraph-level misinformation** in LLM-generated text.  
This project focuses on **sentence-level verification, evidence retrieval, agreement gating, and sequential editing** to improve factual consistency while preserving the original response as much as possible.

### [Hallucination under Adversarial Attack](https://github.com/shivangitripathi2712/hallucination_under_adversarial_attack)
Research implementation for studying how **adversarial prompt perturbations** can trigger hallucinated behavior in LLMs.  
This project explores **OoD prompts, weak semantic perturbations, and adversarial prompt optimization** to analyze model vulnerability and robustness.
